## 功能描述

用户可以为流量列表中的任何请求添加颜色标记（Color Tag）和文字备注（Comment）。颜色标记在列表行首以彩色圆点显示，帮助用户在大量请求中快速识别关注的条目。备注通过弹窗编辑，存储在内存中。

## 用户操作流程

### 添加颜色标记
1. 在 FlowTable 中右键某行 → 弹出上下文菜单
2. 菜单顶部显示 "Color Tag" 区域，排列 6 个颜色圆点 + 1 个清除按钮
3. 点击某个颜色圆点 → 该行左侧出现对应颜色的 8x8 圆点
4. 点击清除按钮 (X) → 移除颜色标记

### 添加备注
1. 右键菜单中点击 "Add Comment"（或已有备注时显示 "Edit Comment"）
2. 弹出对话框，包含多行文本输入框
3. 输入备注内容 → 点击 "Save" 保存
4. 清空内容 → 点击 "Save" 移除备注

## 技术实现

### 前端（Flutter）
- **TagController**: GetxController
  - `_tags: RxMap<String, Color>` — flowId → 标记颜色
  - `_comments: RxMap<String, String>` — flowId → 备注文本
  - 提供 set/remove/get 方法
  - `tagColors`: 静态 List<MapEntry<String, Color>>，6 种预定义颜色
- **_FlowRow**: 行首 Obx 监听 tagCtrl.getTag()，有标记时渲染彩色圆点
- **_ColorSubmenu**: 内嵌在 PopupMenuItem(enabled: false) 中，自行处理点击事件
- **_showCommentDialog**: showDialog 弹出 AlertDialog，TextEditingController 管理输入

### 后端（Swift/KnotWebService）
- 纯前端功能，数据仅存在内存中

## 边界条件与异常处理

- 标记和备注仅存在内存中，应用重启或切换任务后丢失
- 同一 flow 可以同时有颜色标记和备注
- 备注为空字符串时自动移除
- 上下文菜单中的 enabled: false 使 ColorSubmenu 不响应 PopupMenuButton 的关闭逻辑，而由内部 GestureDetector 单独处理

## Proxyman 参考

### 功能对标

Proxyman 的 Color 和 Comment 功能，位于右键菜单中。对应 Proxyman 的 Multiple Filters 中的 Color/Comment 过滤维度。

### Proxyman 界面布局描述

Proxyman 的颜色标记与备注功能：
- **颜色标记**：右键请求 → "Color" 子菜单，提供多种颜色选择（Red、Orange、Yellow、Green、Blue、Purple 等）。选中后请求行背景色变为对应颜色的浅色调
- **备注/Comment**：右键请求 → "Comment"，弹出输入框添加文字备注。备注显示在请求列表的专门列中
- **过滤支持**：Multiple Filters 中支持按 Color 和 Comment 过滤。可以选择 "Has Color"、特定颜色、"Has Comment"、"Comment contains" 等条件
- **视觉展示**：标记颜色以整行背景色呈现（而非仅圆点），视觉效果更醒目
- **持久化**：标记和备注保存在 Session 文件中

### 参考截图

| 截图 | 说明 |
|------|------|
| （文字描述）Proxyman 颜色标记 | 请求列表中，标记了颜色的行整行背景变为对应颜色的浅色调（如红色标记行为浅红背景），视觉上非常醒目。右键菜单中 "Color" 子菜单列出所有可选颜色 |
| （文字描述）Proxyman Comment | 备注文字显示在请求列表的 Comment 列中，可在 Multiple Filters 中按 Comment 内容过滤 |

### 布局优缺点分析

**优点：**
- 整行背景着色比小圆点更醒目，在大量请求中更容易识别
- 支持按颜色和备注过滤，实用性强
- 标记和备注保存在 Session 中，不会丢失
- 备注在列表中直接可见（专门列）

**缺点：**
- 整行着色在深色模式下颜色对比度可能不够
- 颜色选择固定，不支持自定义

### Knot 与 Proxyman 差异

| 对比点 | Proxyman | Knot |
|--------|----------|------|
| 颜色展示 | 整行背景着色 | 行首 8x8 彩色圆点 |
| 备注展示 | 列表专门列显示 | 仅通过右键菜单查看/编辑 |
| 持久化 | 保存在 Session 文件 | 仅内存（重启丢失） |
| 过滤支持 | Multiple Filters 支持 Color/Comment 过滤 | 不支持 |
| 颜色数量 | 多种（含更多选择） | 6 种预定义 |
| 操作方式 | 右键 → Color 子菜单 | 右键 → 颜色圆点行 |

### Knot 中尚未实现的 Proxyman 功能

- **按备注过滤**: 在过滤器中按备注内容筛选
- **备注列显示**: 在请求列表中专门列显示备注文字
- **标记持久化**: 将标记和备注保存到存储中
