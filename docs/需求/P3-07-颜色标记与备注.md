## 功能描述

用户可以为流量列表中的任何请求添加颜色标记（Color Tag）和文字备注（Comment）。颜色标记在列表行首以彩色圆点显示，帮助用户在大量请求中快速识别关注的条目。备注通过弹窗编辑，存储在内存中。

## 用户操作流程

### 添加颜色标记
1. 在 FlowTable 中右键某行 → 弹出上下文菜单
2. 菜单顶部显示 "Color Tag" 区域，排列 6 个颜色圆点 + 1 个清除按钮
3. 点击某个颜色圆点 → 该行左侧出现对应颜色的 8x8 圆点
4. 点击清除按钮 (X) → 移除颜色标记

### 添加备注
1. 右键菜单中点击 "Add Comment"（或已有备注时显示 "Edit Comment"）
2. 弹出对话框，包含多行文本输入框
3. 输入备注内容 → 点击 "Save" 保存
4. 清空内容 → 点击 "Save" 移除备注

## 技术实现

### 前端（Flutter）
- **TagController**: GetxController
  - `_tags: RxMap<String, Color>` — flowId → 标记颜色
  - `_comments: RxMap<String, String>` — flowId → 备注文本
  - 提供 set/remove/get 方法
  - `tagColors`: 静态 List<MapEntry<String, Color>>，6 种预定义颜色
- **_FlowRow**: 行首 Obx 监听 tagCtrl.getTag()，有标记时渲染彩色圆点
- **_ColorSubmenu**: 内嵌在 PopupMenuItem(enabled: false) 中，自行处理点击事件
- **_showCommentDialog**: showDialog 弹出 AlertDialog，TextEditingController 管理输入

### 后端（Swift/KnotWebService）
- 纯前端功能，数据仅存在内存中

## 边界条件与异常处理

- 标记和备注仅存在内存中，应用重启或切换任务后丢失
- 同一 flow 可以同时有颜色标记和备注
- 备注为空字符串时自动移除
- 上下文菜单中的 enabled: false 使 ColorSubmenu 不响应 PopupMenuButton 的关闭逻辑，而由内部 GestureDetector 单独处理
