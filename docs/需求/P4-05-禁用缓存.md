## 功能描述

No Caching 功能提供一个全局开关，启用后代理会移除请求和响应中的缓存相关头部，确保每次请求都能获得服务器的最新响应。适用于调试缓存策略或确保看到最新内容的场景。

## 用户操作流程

1. 点击 GlobalBar → Tools 菜单
2. 在菜单中找到 "No Caching" 项（带 checkbox 图标）
3. 点击切换:
   - 启用: checkbox 变为选中状态，SnackBar 提示 "No Caching enabled"
   - 禁用: checkbox 变为未选中状态，SnackBar 提示 "No Caching disabled"

## 技术实现

### 前端（Flutter）
- **ToolsController**:
  - `noCachingEnabled: RxBool` — 缓存禁用开关状态
  - `toggleNoCaching()`: 切换布尔值
- **GlobalBar._ToolsMenuButton**:
  - PopupMenuItem(value: 'noCaching')
  - 内部 Obx 动态切换 checkbox 图标
  - onSelected 处理: toggle + SnackBar

### 后端（Swift/KnotWebService）
- 当前仅前端状态管理
- 实际功能需要代理引擎支持: 移除 If-Modified-Since / If-None-Match / Cache-Control 等头部

## 边界条件与异常处理

- 开关状态仅在内存中，重启后重置为关闭
- 菜单 Obx 在 PopupMenu 打开期间动态更新

## Proxyman 参考

### 功能对标

Proxyman 的 No Caching 功能（⌥⌘N），位于 Tools → No Caching 菜单中。

### Proxyman 界面布局描述

Proxyman 的 No Caching 功能：
- **触发方式**：Tools 菜单 → "No Caching"（⌥⌘N），勾选/取消勾选切换
- **菜单显示**：启用时菜单项前显示 ✓ 勾选标记
- **请求端处理**：
  - 移除 If-Modified-Since 头
  - 移除 If-None-Match 头
  - 添加 Pragma: no-cache
  - 添加 Cache-Control: no-cache
- **响应端处理**：
  - 移除 Expires 头
  - 移除 Last-Modified 头
  - 移除 ETag 头
  - 添加 Expires: 0
  - 添加 Cache-Control: no-cache
- **实际生效**：在代理引擎层面修改 HTTP 头部，确保绕过缓存

### 布局优缺点分析

**优点：**
- 快捷键 ⌥⌘N 操作便捷
- 在代理引擎层面生效，真正禁用缓存
- 同时处理请求端和响应端的缓存头，覆盖全面
- 菜单勾选状态清晰

**缺点：**
- 全局开关，不支持按域名选择性禁用
- 没有独立的 UI 指示当前状态（需打开菜单确认）

### Knot 与 Proxyman 差异

| 对比点 | Proxyman | Knot |
|--------|----------|------|
| 实际生效 | 代理引擎层面修改 HTTP 头 | 仅 UI 状态（不生效） |
| 快捷键 | ⌥⌘N | 无快捷键 |
| 菜单状态 | ✓ 勾选标记 | Checkbox 图标 |
| 头部处理 | 详细定义（请求端4项+响应端4项） | 未定义 |
| 持久化 | 持久化保存 | 仅内存 |
| 选择性 | 全局 | 全局 |

### Knot 中尚未实现的 Proxyman 功能

- **代理引擎集成**: 需要在代理引擎中实际移除/添加缓存头
- **快捷键 ⌥⌘N**: 快速切换 No Caching
- **详细头部处理规则**: 明确定义请求端和响应端各需处理的 HTTP 头
- **状态持久化**: 保存开关状态到本地存储
- **独立状态指示**: GlobalBar 上显示 No Caching 启用状态图标
