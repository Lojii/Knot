## 功能描述

时序图（Waterfall）以瀑布图形式可视化展示所有请求的时间线分布。每个请求显示为一个水平条形，条形的起始位置和长度反映请求在时间轴上的偏移和耗时。不同阶段用不同颜色区分，帮助用户快速定位慢请求和并发模式。

## 用户操作流程

1. 在 ContentPanel 中点击 "Waterfall" Tab
2. 页面展示所有已捕获请求的时间线
3. 顶部图例说明各阶段颜色含义
4. 每行显示请求摘要 + 彩色条形 + 耗时数值
5. 垂直滚动浏览全部请求

## 界面设计

### 布局结构
```
┌──────────────────────────────────────────────────┐
│ Legend (28px): ■Connect ■TLS ■Request ■TTFB ■Download  [1.5s total] │
├──────────────────────────────────────────────────┤
│ GET api.example.com/v1/us  ████████░░░    45ms │
│ POST cdn.test.io/upload    ░░██████████   120ms │
│ GET static.cdn.io/js/app   ██░░░░░░░░░    12ms │
│ ...                                            │
└──────────────────────────────────────────────────┘
```

### 图例区
- 高度 28px (tableHeaderHeight)
- 左侧: 5 种颜色方块 + 标签（Connect/TLS/Request/TTFB/Download）
- 右侧: 总时间范围（如 "1.5s total"）

### 请求行
- 行高 22px
- 左侧 200px: 请求摘要文本 "{method} {host}{uri}"，超长省略
- 中间: WaterfallBar 自适应宽度的彩色条形
- 右侧 60px: 耗时数值（如 "45ms"），右对齐

### WaterfallBar 组件 (`widgets/waterfall_bar.dart`)
- 基于 CustomPaint 绘制
- 根据 totalDuration 和 startOffset 计算条形的水平位置
- 依次绘制 5 个阶段色块: Connect(橙) → TLS(紫) → Request(蓝) → TTFB(浅绿) → Response(绿)
- 每段最小宽度 1px，防止过窄不可见
- 条形高度 = 容器高度 - 4px（上下各留 2px）

### 时间计算
- `firstStart`: 最早请求的 startedAt
- `lastEnd`: 所有请求中 endedAt 的最大值
- `totalMs`: (lastEnd - firstStart) * 1000，至少 1ms
- 每个请求的 `offsetMs`: (flow.startedAt - firstStart) * 1000

### 当前简化
由于详细时序数据（connectMs/tlsMs 等）在 summary 中不可用，当前使用 durationMs 的 15%/85% 比例近似拆分为 connect 和 response 两段。

## 技术实现

### 前端（Flutter）
- **WaterfallTab**: StatelessWidget，Obx 监听 FlowController.flows
- 列表按时间正序显示（最早的请求在顶部）：`flows[flows.length - 1 - i]`
- **WaterfallBar**: StatelessWidget + CustomPaint
- **_WaterfallPainter**: 逐段绘制矩形，x 坐标按比例映射到画布宽度

### 后端（Swift/KnotWebService）
- 时序数据依赖 FlowDetail 的 connectAt/connectedAt/tlsDoneAt/reqEndAt/rspStartAt 字段
- summary 列表视图不包含详细时序，需逐条加载 detail（当前为简化近似）

## 边界条件与异常处理

- 无请求时显示居中文本 "No requests yet"
- totalDuration <= 0 时 WaterfallBar 返回空 SizedBox
- durationMs 为 null 时显示 "-"
- 条形段宽度最小 clamp 为 1px
