## 功能描述

历史任务管理面板提供对所有抓包任务的浏览、搜索、切换、删除和批量操作能力。用户可以查看过去的抓包会话，快速切换到某个历史任务查看其流量数据，也可以清理不需要的历史记录。

## 用户操作流程

### 普通模式
1. 点击 GlobalBar 的 History 按钮 → 进入历史面板
2. 列表自动加载所有历史任务
3. 搜索框输入关键词 → 按任务名或 ID 实时过滤
4. 点击某个任务 → 切换到该任务并回到抓包页面
5. 右键任务 → 弹出上下文菜单（打开 / 删除）
6. 点击行末 "..." 按钮 → 同上下文菜单

### 编辑模式
1. 点击 "编辑" 按钮 → 进入编辑模式
2. 每行出现 Checkbox，支持多选
3. 工具栏显示: 全选 Checkbox + 已选计数 + "完成" 按钮 + "删除" 按钮
4. 勾选要删除的任务 → 点击 "删除 (N)" → 确认对话框 → 批量删除
5. 点击 "完成" 退出编辑模式

## 界面设计

### 布局结构
```
┌──────────────────────────────────────────────────┐
│ Toolbar (38px): "Capture History" + N tasks + 编辑 + 搜索框 │
├──────────────────────────────────────────────────┤
│ ┌ TaskRow ────────────────────────────────────┐  │
│ │ ● Task 1  2026-03-20 14:30  42 flows ↑1.2K ↓45.3M [46.5M] ...│
│ ├─────────────────────────────────────────────┤  │
│ │   Task 2  2026-03-19 10:15  18 flows ↑0.5K ↓12.1M [12.6M] ...│
│ └─────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────┘
```

### 普通模式工具栏
- "Capture History" 标题 + 任务总数 + "编辑" 按钮 + 搜索框 (200px)

### 编辑模式工具栏
- 全选 Checkbox + "已选 N / M" + "完成" 按钮 + 右侧红色 "删除 (N)" 按钮

### 任务行 (_TaskRow)
- 左侧: 编辑模式下显示 Checkbox；普通模式下当前任务显示绿色圆点
- 任务名 (120px, 粗体高亮当前任务)
- 创建时间 (140px, 格式 YYYY-MM-DD HH:MM)
- 流量数 (80px, "N flows")
- 上行 (80px, ↑ 图标 + 字节数)
- 下行 (80px, ↓ 图标 + 字节数)
- 总流量 badge（圆角背景）
- "..." 按钮（非编辑模式）

### 上下文菜单
- "打开": 切换到该任务 + 返回抓包页面
- "删除": 确认对话框后删除

### 删除确认对话框
- 标题: "删除确认"
- 内容: "确定删除 Task {id} 及其所有数据？" 或 "确定删除 N 个任务及其所有数据？"
- 按钮: "取消"(灰) + "删除"(红)

### 删除进行中遮罩
- 半透明黑色遮罩 + 居中卡片 + CircularProgressIndicator + "正在删除..."

## 技术实现

### 前端（Flutter）
- **HistoryPanel**: StatefulWidget，管理搜索、编辑模式、选中集合、删除状态
- 搜索过滤: 本地 toLowerCase contains 匹配任务名和 ID
- 选中管理: `_selectedIds: Set<int>`
- 全选/取消: 仅操作当前可见（过滤后）的任务
- 编辑/删除状态通过 `setState` 管理（非 GetX）

### 后端（Swift/KnotWebService）
- **GET /api/tasks**: 返回所有任务列表
- **DELETE /api/tasks/{taskId}**: 删除单个任务及其数据
- **POST /api/tasks/batch-delete**: body `{"ids": [1,2,3]}`，批量删除

## 边界条件与异常处理

- 无历史任务时显示 "No capture history"
- 搜索无结果时同上
- 删除失败时 SnackBar 提示 "删除失败: {error}" 或 "批量删除失败: {error}"
- 删除进行中禁止其他操作（遮罩层）
- 加载中显示 CircularProgressIndicator（非删除期间）
