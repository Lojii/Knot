## 功能描述

Compose 页面是一个完整的 HTTP 请求构造和发送工具（类似 Postman）。用户可以自定义 HTTP 方法、URL、Headers、Query 参数和 Body，发送请求后在右侧查看响应结果。同时支持从已捕获的请求预填充数据（"Edit & Resend"）。

## 用户操作流程

### 手动构造
1. 点击 GlobalBar 的 Compose 按钮 → 进入构造页面
2. 选择 HTTP Method（下拉菜单: GET/POST/PUT/DELETE/PATCH/HEAD/OPTIONS）
3. 输入 URL（如 https://api.example.com/users）
4. 添加 Headers（键值对编辑器，可增删行）
5. 添加 Query 参数（自动与 URL 双向同步）
6. 编写 Body（Raw/JSON/Form 三种格式 hint）
7. 点击 "Send" → 右侧显示响应

### 从捕获请求预填充
1. 在流量详情面板点击 "Edit & Resend"，或右键 → "Open in Compose"
2. 自动跳转到 Compose 页面，预填充 method/url/headers/body
3. 修改后发送

## 界面设计

### 整体布局
```
┌────────────────────┬────────────────────┐
│  Request Editor    │  Response Viewer   │
│                    │                    │
│ [Method▾] [URL___] [Send]              │
│                    │  200 OK  45ms      │
│ Headers            │                    │
│ [key] [value] ✕    │  Response Headers  │
│ [key] [value] ✕    │  key: value        │
│ + Add              │                    │
│                    │  Response Body     │
│ Query Parameters   │  BodyViewer        │
│ [key] [value] ✕    │                    │
│ + Add              │                    │
│                    │                    │
│ Body               │                    │
│ [Raw] [JSON] [Form]│                    │
│ ┌────────────────┐ │                    │
│ │ request body   │ │                    │
│ └────────────────┘ │                    │
└────────────────────┴────────────────────┘
```

### 请求编辑器（左半部分）
- **Method + URL**: 横排，Method 下拉菜单（颜色编码） + URL 输入框 + Send 按钮
- **Headers 编辑器**: 可增删行的键值对列表，每行: [key 输入框] [value 输入框] [X 删除按钮]
- **Query 参数编辑器**: 同 Headers 格式，与 URL 双向同步
- **Body 编辑器**: 三种格式 Tab (Raw/JSON/Form) + 200px 高多行文本框

### URL 与 Query 双向同步
- 编辑 URL → 自动解析 query params 填入 Query 编辑器
- 编辑 Query 行 → 自动更新 URL 的 query string
- 使用 `_syncingQuery` 标志防止循环更新

### 响应查看器（右半部分）
- 未发送时: 居中图标 + "Send a request to see the response"
- 发送中: CircularProgressIndicator
- 发送完成:
  - Status Badge: 彩色背景 + 状态码 + 状态短语 + 耗时
  - Response Headers: KeyValueTable
  - Response Body: BodyViewer（自动检测 content-type）

### Method 颜色
- 下拉菜单每项颜色编码: GET=绿, POST=橙, PUT=蓝, DELETE=红, PATCH=紫

### 预填充流程
- AppPageController 存储预填充数据: composePrefillMethod/Url/Headers/Body
- ComposePage.didChangeDependencies 中一次性应用预填充
- 应用后立即 clearComposePrefill

## 技术实现

### 前端（Flutter）
- **ComposePage**: StatefulWidget，管理所有表单状态
- Header/Query 行: `List<(TextEditingController, TextEditingController)>`
- 发送请求: 使用 `package:http` 直接发送（不经过代理）
- 响应: http.Request → http.Client().send() → Response.fromStream()
- 计时: Stopwatch 精确测量耗时

### 后端（Swift/KnotWebService）
- 请求直接由 Flutter HTTP 客户端发送，不经过 KnotWebService 代理

## 边界条件与异常处理

- URL 为空时 Send 不执行
- URL 不含 scheme 时自动添加 `https://`
- GET/HEAD 请求不发送 body
- 请求失败时右侧显示 "Error: {exception}"
- 键值对编辑器至少保留一行（禁止删除最后一行）
