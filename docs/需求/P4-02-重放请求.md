## 功能描述

用户可以快速重放（Repeat）一个已捕获的 HTTP 请求，使用原始的 method、URL 和 headers 发送相同的请求，并查看响应结果。支持右键菜单和键盘快捷键两种触发方式。

## 用户操作流程

### 方式一: 右键菜单
1. 在 FlowTable 中右键某行
2. 点击 "Repeat"
3. 自动加载详情（如未加载）→ 发送请求
4. SnackBar 显示结果: "{statusCode} ({elapsedMs}ms)" 或 "Repeat failed: {error}"

### 方式二: 快捷键
1. 选中某条流量 → 按 Cmd+R
2. 同上流程

## 界面设计

### 右键菜单项
- Icon: replay (16px)
- Text: "Repeat"

### 反馈
- 成功: SnackBar "{statusCode} ({elapsedMs}ms)"，3s 显示
- 失败: SnackBar "Repeat failed: {error}"，3s 显示

## 技术实现

### RequestSender 类 (`utils/request_sender.dart`)

#### repeat(FlowSummary flow, Map<String, dynamic> detail) → RepeatResult

1. **构建 URL**: scheme (https if HTTPS/H2, else http) + host + uri
2. **提取 Headers**: 从 detail.metadata.requestHeaders 提取
   - 跳过 hop-by-hop 和代理头: host / connection / proxy-connection / transfer-encoding / content-length
3. **发送请求**: http.Request(method, uri) + headers → Client.send()
4. **返回结果**: RepeatResult(statusCode, elapsed, body, headers)

#### extractHeaders(detail) → Map<String, String>
- 提取请求头用于 Compose 预填充（跳过 host/connection/transfer-encoding/content-length）

#### buildUrl(FlowSummary) → String
- scheme + "://" + host + uri

### RepeatResult 数据结构
| 字段 | 类型 | 说明 |
|------|------|------|
| statusCode | int | HTTP 响应状态码 |
| elapsed | Duration | 请求耗时 |
| body | String | 响应内容 |
| headers | Map<String, String> | 响应头 |

### 调用时机
- 右键菜单: _FlowRow._repeatRequest() — 先检查 detail 是否已加载
- 快捷键: RepeatRequestIntent Action — 异步闭包中执行

### 后端（Swift/KnotWebService）
- 请求直接由 Flutter HTTP 客户端发送，不经过代理

## 边界条件与异常处理

- 未选中流量时不执行
- 详情未加载时先加载（需 taskId 非 null）
- 网络错误时捕获异常显示 SnackBar
- context.mounted 检查防止已卸载 widget 操作
