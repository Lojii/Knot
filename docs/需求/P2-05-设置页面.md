## 功能描述

设置页面提供应用配置的查看入口，当前为只读信息展示面板，包含连接配置、外观设置和应用信息三个分区。通过 GlobalBar 的 Settings 按钮打开，内嵌在主布局中（非独立页面）。

## 用户操作流程

1. 点击 GlobalBar 右侧的 Settings 图标
2. 内容区域切换为设置面板（GlobalBar 和 StatusBar 保持不变）
3. 浏览各分区的配置信息
4. 再次点击 Settings 图标或 Home 图标返回抓包页面

### 设计规范
- 整体 ListView + 16px 内边距
- 每个分区: 分区标题（13px, 粗体, hintColor） + 8px 间距 + 圆角卡片容器

## 技术实现

### 前端（Flutter）
- **SettingsPanel**: StatelessWidget

- 三个分区通过 `_section()` 工厂方法构建
- 信息项通过 `_infoTile()` 工厂方法构建

## Proxyman 参考

### 功能对标

Proxyman 的 Preferences 窗口（⌘,），包含 General、SSL、Tools、Advanced 等多个配置面板。

### Proxyman 界面布局描述

Proxyman 的设置采用标准 macOS Preferences 窗口布局：
- **General Tab**：代理端口配置（默认 9090）、自动启动选项、自动清除选项、主题选择（Light/Dark/System）
- **SSL Tab**：CA 证书管理（生成、安装、信任）、SSL Proxying List（Include/Exclude 域名列表）、证书导出
- **Tools Tab**：External Proxy 配置（HTTP/HTTPS/SOCKS 代理）、Access Control（允许/拒绝远程设备连接）
- **Advanced Tab**：日志级别、网络超时配置、缓存设置、Protobuf .desc 文件路径
- **License Tab**：许可证信息和激活
- 窗口顶部有 Tab 选择器（图标+文字），类似 System Preferences

### 参考截图

| （文字描述）Proxyman Preferences - SSL | SSL 证书管理区域，包含 "Install Certificate on this Mac" 按钮、证书状态指示灯（绿色=已信任）、SSL Proxying List 管理入口 |

### 布局优缺点分析

**优点：**
- 标准 macOS 偏好设置交互范式，用户零学习成本
- 功能分类清晰，Tab 分区合理
- CA 证书一键安装/信任，对新手友好
- 代理端口可自定义

**缺点：**
- 设置项较多，初次使用可能不知道配什么
- 部分高级设置对新手不友好

### Knot 与 Proxyman 差异

| 对比点 | Proxyman | Knot |
|--------|----------|------|
| 设置入口 | 独立 Preferences 窗口 | 内嵌在主界面的 Settings 面板 |
| 可配置项 | 丰富（端口/SSL/代理/高级） | 极简（仅只读信息展示） |
| 主题切换 | 三选一可操作 | 仅显示 "Follow system"（不可操作） |
| 代理端口 | 可自定义 | 不可配置 |
| CA 证书 | 完整管理（生成/安装/信任/导出） | 无 |
| External Proxy | 支持配置上游代理 | 无 |

### Knot 中尚未实现的 Proxyman 功能

- **代理端口配置**: 自定义代理监听端口
- **CA 证书管理**: 生成、安装、信任根证书的完整向导
- **SSL Proxying List**: 配置哪些域名启用 SSL 解密
- **External Proxy**: 配置上游 HTTP/SOCKS 代理
- **Access Control**: 控制远程设备连接权限
- **主题切换**: Light/Dark/System 三选一
- **日志级别设置**: 控制调试日志输出级别
- **数据存储路径**: 配置数据保存位置
