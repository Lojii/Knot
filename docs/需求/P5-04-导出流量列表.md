## 功能描述

将当前流量列表导出为 CSV 或 JSON 格式的文件，便于在电子表格（Excel/Google Sheets）或数据分析工具中进一步处理。导出的是流量摘要信息（非详情），包括 method、host、path、status、size、time、protocol 等字段。

## 用户操作流程

### 导出 CSV
1. 点击 GlobalBar → Tools 菜单 → "Export List as CSV"
2. 成功: SnackBar "CSV exported to {path}"
3. 文件保存: `~/Desktop/knot-flows-{timestamp}.csv`

### 导出 JSON
1. 点击 GlobalBar → Tools 菜单 → "Export List as JSON"
2. 成功: SnackBar "JSON exported to {path}"
3. 文件保存: `~/Desktop/knot-flows-{timestamp}.json`

## 界面设计

### Tools 菜单项
- "Export List as CSV"（table_chart_outlined 图标）
- "Export List as JSON"（data_object 图标）

- 成功: SnackBar "{format} exported to {path}"（4s 显示）

## 技术实现

### ListExport 类 (`utils/list_export.dart`)

#### toCsv(List<FlowSummary>) → String
CSV 格式:
```csv
Method,Host,Path,Status,Size,Time,Protocol
GET,api.example.com,/v1/users,200,1234,45,HTTPS
POST,cdn.test.io,/upload,201,56789,120,HTTP
```

- 表头: Method,Host,Path,Status,Size,Time,Protocol
- 每行: 各字段逗号分隔
- 特殊字符转义: 包含逗号/引号/换行的值用双引号包裹，内部引号转义为 `""`
- Time: durationMs 取整，null 为空

#### toJson(List<FlowSummary>) → String
JSON 格式:
```json
[
  {
    "method": "GET",
    "host": "api.example.com",
    "path": "/v1/users",
    "status": 200,
    "size": 1234,
    "time": 45,
    "protocol": "HTTPS",
    "flowId": "abc-123",
    "startedAt": 1711000000.0,
    "uploadBytes": 100,
    "contentType": "application/json"
  }
]
```

- JsonEncoder.withIndent('  ') 格式化
- 比 CSV 多导出: flowId / startedAt / uploadBytes / contentType

#### writeToDesktop(content, extension) → String
- 路径: `$HOME/Desktop/knot-flows-{timestamp}.{extension}`
- dart:io File.writeAsString

### 调用流程（GlobalBar._ToolsMenuButton）
1. 检查 flowCtrl.flows.isEmpty → 提示
2. 调用 ListExport.toCsv 或 toJson
3. 写入桌面文件
4. SnackBar 显示结果路径

### 后端（Swift/KnotWebService）
- 纯前端操作，数据来自 FlowController.flows 内存数据

## 边界条件与异常处理

- 无流量时提示 "No flows to export"
- 文件写入失败时 SnackBar 报错
- CSV 字段包含逗号/引号/换行时正确转义
- JSON 中 time 为 null 时输出 null

## Proxyman 参考

### 功能对标

Proxyman 没有直接的 CSV/JSON 列表导出功能。流量数据导出主要通过 HAR 和 .proxyman 格式。但 Proxyman 支持复制请求信息到剪贴板。

### Proxyman 界面布局描述

Proxyman 的数据导出相关功能：
- **File → Export → HAR**: 导出为 HAR 格式（包含完整详情）
- **File → Export → Proxyman**: 导出为 .proxyman 格式
- **Copy 功能**: 右键 → Copy 可复制请求的 URL、cURL 等信息
- **没有 CSV/JSON 列表导出**: Proxyman 不提供将流量列表导出为 CSV 或 JSON 摘要格式的功能
- **没有表格数据导出**: 不支持将流量列表表格直接导出用于电子表格分析

### 参考截图

| 截图 | 说明 |
|------|------|
| （文字描述）Proxyman Export 菜单 | File → Export 子菜单仅包含 HAR 和 Proxyman 两种格式，不提供 CSV/JSON 列表格式。Copy 子菜单支持复制 URL 和 cURL |

### 布局优缺点分析

**优点：**
- HAR 格式包含完整信息，通用性强
- .proxyman 格式保留所有元数据

**缺点：**
- 没有轻量级的列表导出（CSV/JSON 摘要）
- 不方便在 Excel/Google Sheets 中分析
- 不支持自定义导出字段

### Knot 与 Proxyman 差异

| 对比点 | Proxyman | Knot |
|--------|----------|------|
| CSV 导出 | 不支持 | 支持 |
| JSON 摘要导出 | 不支持 | 支持 |
| HAR 导出 | 支持 | 支持 |
| 保存位置 | 文件选择器 | 固定桌面 |
| 选择性导出 | 全部或选中 | 仅全部 |
| 字段自定义 | 不支持 | 不支持 |

### Knot 中尚未实现的 Proxyman 功能

- **文件保存对话框**: 使用系统文件选择器让用户自选保存位置
- **选择性导出**: 仅导出选中或过滤后的请求
- 注：CSV/JSON 列表导出是 Knot 的特色功能，Proxyman 未提供此类轻量级导出。Knot 在此处具有差异化优势。
