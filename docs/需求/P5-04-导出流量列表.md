## 功能描述

将当前流量列表导出为 CSV 或 JSON 格式的文件，便于在电子表格（Excel/Google Sheets）或数据分析工具中进一步处理。导出的是流量摘要信息（非详情），包括 method、host、path、status、size、time、protocol 等字段。

## 用户操作流程

### 导出 CSV
1. 点击 GlobalBar → Tools 菜单 → "Export List as CSV"
2. 成功: SnackBar "CSV exported to {path}"
3. 文件保存: `~/Desktop/knot-flows-{timestamp}.csv`

### 导出 JSON
1. 点击 GlobalBar → Tools 菜单 → "Export List as JSON"
2. 成功: SnackBar "JSON exported to {path}"
3. 文件保存: `~/Desktop/knot-flows-{timestamp}.json`

## 技术实现

### ListExport 类 (`utils/list_export.dart`)

#### toCsv(List<FlowSummary>) → String
CSV 格式:
```csv
Method,Host,Path,Status,Size,Time,Protocol
GET,api.example.com,/v1/users,200,1234,45,HTTPS
POST,cdn.test.io,/upload,201,56789,120,HTTP
```

- 表头: Method,Host,Path,Status,Size,Time,Protocol
- 每行: 各字段逗号分隔
- 特殊字符转义: 包含逗号/引号/换行的值用双引号包裹，内部引号转义为 `""`
- Time: durationMs 取整，null 为空

#### toJson(List<FlowSummary>) → String
JSON 格式:
```json
[
  {
    "method": "GET",
    "host": "api.example.com",
    "path": "/v1/users",
    "status": 200,
    "size": 1234,
    "time": 45,
    "protocol": "HTTPS",
    "flowId": "abc-123",
    "startedAt": 1711000000.0,
    "uploadBytes": 100,
    "contentType": "application/json"
  }
]
```

- JsonEncoder.withIndent('  ') 格式化
- 比 CSV 多导出: flowId / startedAt / uploadBytes / contentType

#### writeToDesktop(content, extension) → String
- 路径: `$HOME/Desktop/knot-flows-{timestamp}.{extension}`
- dart:io File.writeAsString

### 调用流程（GlobalBar._ToolsMenuButton）
1. 检查 flowCtrl.flows.isEmpty → 提示
2. 调用 ListExport.toCsv 或 toJson
3. 写入桌面文件
4. SnackBar 显示结果路径

### 后端（Swift/KnotWebService）
- 纯前端操作，数据来自 FlowController.flows 内存数据

## 边界条件与异常处理

- 无流量时提示 "No flows to export"
- 文件写入失败时 SnackBar 报错
- CSV 字段包含逗号/引号/换行时正确转义
- JSON 中 time 为 null 时输出 null
