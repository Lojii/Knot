## 功能描述

Allow/Block List 提供域名级别的流量过滤规则管理。Allow List（白名单）模式下仅显示匹配域名的流量；Block List（黑名单）模式下隐藏匹配域名的流量。两个列表在同一面板的两个 Tab 中管理。

## 用户操作流程

1. 点击 GlobalBar → Tools 菜单 → "Allow/Block List"
2. 进入 Allow/Block 面板，默认显示 Allow List Tab
3. 点击 "Add" 按钮 → 弹出对话框输入域名模式（如 `*.example.com`）
4. 确认添加 → 域名出现在列表中
5. 点击行尾的删除按钮移除条目
6. 切换到 Block List Tab 进行同样操作

## 技术实现

### 前端（Flutter）
- **AllowBlockPanel**: StatelessWidget, DefaultTabController(length: 2)
- **_DomainListTab**: 复用组件，通过 `isAllow` 参数区分
- **ToolsController**:
  - `allowList: RxList<String>` — 白名单域名列表
  - `blockList: RxList<String>` — 黑名单域名列表
  - addToAllowList / removeFromAllowList / addToBlockList / removeFromBlockList
  - 添加时检查非空且不重复

### 后端（Swift/KnotWebService）
- 当前列表仅存在前端内存中
- 需要同步到代理引擎实际执行过滤

## 边界条件与异常处理

- 空字符串不允许添加
- 重复条目不会重复添加（contains 检查）
- 对话框 dispose 时清理 TextEditingController

## Proxyman 参考

### 功能对标

Proxyman 的 SSL Proxying List（Include/Exclude）以及 Block List 功能。位于 Preferences → SSL 和 Tools 菜单中。

### Proxyman 界面布局描述

Proxyman 的域名过滤管理分为两个部分：

**SSL Proxying List（Include/Exclude）：**
- 位于 Preferences → SSL → SSL Proxying List
- 弹窗管理界面，分 Include List 和 Exclude List 两个区域
- 支持通配符：*（所有域名）、*.domain.com（子域名）、v?.domain.com（单字符通配）
- 右键 Source List 的域名可快速添加到 Include/Exclude
- 右键 App 可添加该 App 所有域名
- 快捷键 ⌘⌥P 快速切换

**Block List：**
- 阻止特定域名的流量通过代理
- 右键域名 → "Block this domain"
- 被阻止的请求返回错误

**Access Control：**
- 控制远程设备连接：Allow All / Disallow All / Specify by IP
- 位于 Preferences → Tools

### 布局优缺点分析

**优点：**
- Include/Exclude 分区清晰
- 通配符支持强大（*、v? 等）
- 右键域名可快速添加，操作路径短
- ⌘⌥P 快捷键方便
- 实际生效（在代理引擎层面过滤）

**缺点：**
- SSL Proxying List 和 Block List 分散在不同位置
- 没有统一的规则管理视图
- 不支持正则表达式

### Knot 与 Proxyman 差异

| 对比点 | Proxyman | Knot |
|--------|----------|------|
| 功能定位 | SSL Proxying + Block List 分开 | Allow/Block 统一管理 |
| 代理引擎集成 | 实际生效 | 仅 UI 管理（不生效） |
| 通配符 | 支持 * / v? | 界面支持但引擎未集成 |
| 快捷添加 | 右键域名快速添加 | 需进入管理面板手动添加 |
| 快捷键 | ⌘⌥P | 无 |
| 持久化 | 持久化保存 | 仅内存 |
| 规则开关 | 不支持单条开关 | 不支持单条开关 |
| Access Control | 支持 IP 级别控制 | 无 |

### Knot 中尚未实现的 Proxyman 功能

- **代理引擎集成**: 规则需同步到代理引擎才能实际生效
- **右键快速添加**: 从域名树右键直接添加到 Allow/Block List
- **快捷键 ⌘⌥P**: SSL Proxying 快捷切换
- **Access Control**: IP 级别的远程设备连接控制
- **规则持久化**: 将列表保存到本地存储
- **单条规则开关**: 启用/禁用单条规则而不删除
- **通配符语法说明**: 提供通配符使用说明
