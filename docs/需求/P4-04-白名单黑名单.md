## 功能描述

Allow/Block List 提供域名级别的流量过滤规则管理。Allow List（白名单）模式下仅显示匹配域名的流量；Block List（黑名单）模式下隐藏匹配域名的流量。两个列表在同一面板的两个 Tab 中管理。

## 用户操作流程

1. 点击 GlobalBar → Tools 菜单 → "Allow/Block List"
2. 进入 Allow/Block 面板，默认显示 Allow List Tab
3. 点击 "Add" 按钮 → 弹出对话框输入域名模式（如 `*.example.com`）
4. 确认添加 → 域名出现在列表中
5. 点击行尾的删除按钮移除条目
6. 切换到 Block List Tab 进行同样操作

## 界面设计

### 面板布局
```
┌──────────────────────────────────────────────────┐
│ [Allow List] [Block List]  ← Tab Bar (38px)      │
├──────────────────────────────────────────────────┤
│ ✅ Allow List: only show traffic from these domains  [Add] │
├──────────────────────────────────────────────────┤
│ *.example.com                                [🗑]│
│ api.test.io                                  [🗑]│
│ cdn.production.com                           [🗑]│
└──────────────────────────────────────────────────┘
```

### Tab Bar
- 两个 Tab: "Allow List" / "Block List"
- isScrollable, tabAlignment: start

### 说明栏
- surfaceContainerLow 背景
- 图标 + 说明文字:
  - Allow: "Allow List: only show traffic from these domains"
  - Block: "Block List: hide traffic from these domains"
- 右侧 "Add" 按钮

### 列表项
- ListTile(dense: true)
- 标题: 等宽字体显示域名模式 (12px)
- 右侧: 删除按钮 (delete_outline, 16px, hintColor)

### 空状态
- 居中文本: "No allow list entries" 或 "No block list entries"

### 添加对话框
- 标题: "Add to Allow List" 或 "Add to Block List"
- 输入框: 等宽字体, hint "*.example.com", autofocus
- 宽度 360px
- 支持 Enter 键提交
- 按钮: "Cancel" + "Add"

## 技术实现

### 前端（Flutter）
- **AllowBlockPanel**: StatelessWidget, DefaultTabController(length: 2)
- **_DomainListTab**: 复用组件，通过 `isAllow` 参数区分
- **ToolsController**:
  - `allowList: RxList<String>` — 白名单域名列表
  - `blockList: RxList<String>` — 黑名单域名列表
  - addToAllowList / removeFromAllowList / addToBlockList / removeFromBlockList
  - 添加时检查非空且不重复

### 后端（Swift/KnotWebService）
- 当前列表仅存在前端内存中
- 需要同步到代理引擎实际执行过滤

## 边界条件与异常处理

- 空字符串不允许添加
- 重复条目不会重复添加（contains 检查）
- 对话框 dispose 时清理 TextEditingController
