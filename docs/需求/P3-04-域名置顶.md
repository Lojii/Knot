## 功能描述

在域名树面板中，用户可以将常用或关注的域名"置顶"（Pin），置顶的域名会在列表顶部显示一个独立分区，带星标图标，方便快速访问。支持右键菜单操作。

## 用户操作流程

1. 在 TreePanel 的域名列表中右键某个域名
2. 弹出上下文菜单 → 点击 "Pin"
3. 该域名移到列表顶部的 "Pinned" 分区，显示星标图标
4. 再次右键 → 点击 "Unpin" 取消置顶

## 界面设计

### 域名树布局
```
┌──────────────┐
│ Domains    8 │  ← 表头（域名总数）
├──────────────┤
│ All Domains  │  ← 全部域名选项
├──────────────┤
│ ⭐ Pinned     │  ← 置顶分区标题（仅当有置顶域名时显示）
│ ★ api.test.io 12│
│ ★ cdn.app.co  5│
├──────────────┤
│ other.com     3│  ← 普通域名（按请求数降序）
│ static.io     1│
└──────────────┘
```

### 域名行 (_DomainTile)
- ExpansionTile 可展开查看子请求
- 置顶域名: 左侧 14px 金色星标图标
- 右侧: 子请求数量（灰色, XS 字号）
- 展开后: 子项 ListTile 显示 "{method} {uri}"

### 右键菜单
- Pin / Unpin（星标图标 + 文字）
- 置顶状态下显示 "Unpin"（空心星），非置顶显示 "Pin"（实心星）

### 分区间的视觉分隔
- Pinned 分区标题: "⭐ Pinned"（XS 字号, 粗体, hintColor）
- 分区底部: Divider(height: 1)

## 技术实现

### 前端（Flutter）
- **TreeController**:
  - `pinnedDomains: RxSet<String>` — 置顶域名集合
  - `togglePin(domain)`: 切换置顶状态，触发 buildTree 重建
  - `isPinned(domain)`: 查询是否置顶
- **buildTree()**:
  - 按 host 分组流量
  - 排序规则: 置顶 > 非置顶，同级内按 children.length 降序
- **TreePanel**: 将 tree 列表拆分为 pinned + unpinned 两部分分别渲染

### 后端（Swift/KnotWebService）
- 纯前端功能，无后端交互

## 边界条件与异常处理

- 无置顶域名时不显示 Pinned 分区
- 置顶域名在流量被清空后仍保留在集合中（但树中不再显示）
- 域名为空字符串时 isPinned 返回 false

## Proxyman 参考

### 功能对标

Proxyman 的 Source List（左侧域名树）中的域名管理功能。Proxyman 没有直接的"置顶"功能，但有 Favorite（收藏）和 SSL Proxying 相关操作。

### Proxyman 界面布局描述

Proxyman 左侧 Source List 的域名管理：
- **域名树结构**：按域名自动分组，每个域名显示请求计数
- **右键菜单**：右键域名可以选择 "Enable SSL Proxying"（⌘⌥P）、"Block this domain"、"Add to Allow List" 等
- **搜索过滤**：Source List 顶部有搜索框，可过滤域名列表
- **排序方式**：默认按请求数量降序排列
- **没有置顶/Pin 功能**：Proxyman 不支持将域名固定在列表顶部
- **App 分组**：除域名分组外，还支持按来源 App 分组

### 布局优缺点分析

**优点：**
- 右键操作丰富（SSL Proxying、Block、Allow 等）
- App 分组功能独特，可按应用查看流量
- 搜索框方便快速定位域名

**缺点：**
- 没有置顶/Pin 功能，无法将常用域名固定在顶部
- 域名列表在请求量大时可能很长，缺少收藏/分组管理

### Knot 与 Proxyman 差异

| 对比点 | Proxyman | Knot |
|--------|----------|------|
| 域名置顶 | 不支持 | 支持 Pin 置顶到顶部分区 |
| 右键操作 | SSL Proxying / Block / Allow | Pin / Unpin |
| 搜索 | Source List 内搜索 | 无域名搜索 |
| 分组方式 | 域名 + App | 仅域名 |
| 排序 | 按请求数降序 | 置顶优先 + 按请求数降序 |

### Knot 中尚未实现的 Proxyman 功能

- **右键 SSL Proxying**: 右键域名快速启用/禁用 SSL 解密
- **右键 Block/Allow**: 右键域名快速添加到 Block/Allow List
- **域名搜索**: Source List 内搜索过滤域名
- **App 分组**: 按来源应用分组显示请求
