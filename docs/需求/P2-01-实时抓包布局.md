## 功能描述

实时抓包页面是 Knot 的核心界面，采用 5 行垂直布局 + 嵌套分栏结构。整体布局模仿 Charles/Proxyman 等专业抓包工具的经典设计，将全局导航、工具操作、过滤条件、内容区域和状态信息分层展示。

## 用户操作流程

1. 启动应用 → 默认进入实时抓包页面
2. GlobalBar 显示当前任务名 + 连接状态 + 页面切换按钮
3. Toolbar 提供开始/停止、清除、搜索操作
4. FilterBar 通过 Chip 快速筛选协议和状态码
5. Content 区域左右分栏：左侧域名树 + 右侧内容面板（含 List/Waterfall/Dashboard 三个 Tab）
6. List Tab 上下分栏：上方流量表 + 下方详情面板（7 个 Tab）
7. StatusBar 显示实时统计指标

## 界面设计

### 整体结构（从上到下）

```
┌─────────────────────────────────────────────────┐
│ GlobalBar (38px) — 任务名 + 连接状态 + 导航     │
├─────────────────────────────────────────────────┤
│ Toolbar (38px) — 开始/停止 + 清除 + 搜索框     │
├─────────────────────────────────────────────────┤
│ FilterBar (34px) — 协议 + 状态码 Chip 筛选      │
├─────────┬───────────────────────────────────────┤
│ TreePanel│ ContentPanel                          │
│ (220px) │ ┌─Tab: List / Waterfall / Dashboard─┐ │
│ 域名树   │ │ FlowTable (上半)                  │ │
│ (可拖拽  │ ├──────────────────────────────────┤ │
│  宽度)   │ │ FlowDetailPanel (下半, 7 tabs)   │ │
│         │ └──────────────────────────────────┘ │
├─────────┴───────────────────────────────────────┤
│ StatusBar (26px) — 请求数 + 流量 + 内存 + 连接  │
└─────────────────────────────────────────────────┘
```

### GlobalBar (`global_bar.dart`)
- 高度 38px，macOS 下左侧预留 78px 给交通灯按钮
- 左侧: Home 按钮 → 任务名称 → ConnectionIndicator → Protocol/TCP 切换按钮
- 右侧: Compose → Tools(弹出菜单) → History → Settings
- Tools 菜单包含: Map Remote / Allow-Block List / No Caching / Export HAR / Import HAR / Export CSV / Export JSON / Diff Tool

### Toolbar (`toolbar.dart`)
- 高度 38px
- 左侧: 开始/停止按钮（绿色播放/红色停止图标） + 清除按钮
- 右侧: 搜索框 (240px 宽, 30px 高, 300ms debounce)
- 搜索调用 FlowController.search()

### FilterBar (`filter_bar.dart`)
- 高度 34px
- 协议过滤: HTTP / HTTPS / WS / H2
- 状态码过滤: 2xx / 3xx / 4xx / 5xx
- 选中态 Chip 有蓝色背景+边框高亮
- 点击触发 FilterController.toggle + FlowController.reloadFromFirstPage

### 分栏组件
使用 `multi_split_view` 包实现可拖拽分栏:
- 水平分栏: TreePanel (min 150px, 初始 220px) + ContentPanel (min 300px)
- 垂直分栏 (List Tab内): FlowTable (min 100px, 初始 300px) + FlowDetailPanel (min 100px)

### StatusBar (`status_bar.dart`)
- 高度 26px
- 显示: {total} requests | Up {bytes} Down {bytes} | Mem {MB} MB | {n} conn
- 数据来自 LiveController 的实时指标

### ConnectionIndicator (`widgets/connection_indicator.dart`)
- 三种状态: 绿点 Connected / 橙点 Connecting... / 红点 Disconnected
- 圆点 8x8 + 状态文字

## 技术实现

### 前端（Flutter）
- **CapturePage**: 顶层 Scaffold，Column 包含 GlobalBar + 内容切换（Obx 监听 AppPageController）+ StatusBar
- **_CaptureContent**: 内嵌 Shortcuts + Actions 注册键盘快捷键，Column 包含 Toolbar + FilterBar + MultiSplitView
- **ContentPanel**: TabController(length: 3) 管理 List/Waterfall/Dashboard 三个 Tab
- **页面路由**: 通过 AppPageController.currentPage 枚举切换，不使用 Navigator

### 后端（Swift/KnotWebService）
- GlobalBar 的 Tools 菜单触发 HAR 导出/导入等操作
- StatusBar 数据来自 WebSocket 推送的 metrics 和 stats 消息

## 边界条件与异常处理

- 空流量时 FlowTable 显示居中文本 "No requests captured"
- WebSocket 断开时 ConnectionIndicator 显示红色 Disconnected
- 搜索框自带 300ms debounce 防抖
- 分栏最小宽度限制防止过度拖拽

## Proxyman 参考

### 功能对标

Proxyman 的主界面布局（Main Window），位于应用启动后的默认视图。

### Proxyman 界面布局描述

Proxyman 主界面同样采用多行垂直 + 嵌套分栏结构：
- **顶部工具栏（约 40px）**：左侧为录制按钮（红色圆点，点击开始/停止录制）、清除按钮（垃圾桶图标）；中间为搜索框（支持实时过滤）；右侧为布局切换按钮（水平/垂直分栏）、过滤器按钮
- **左侧 Source List（约 220px）**：按域名分组的树形结构，每个域名显示请求计数。支持右键 Enable SSL Proxying。顶部有 "All Domains" 入口。支持按 App 分组（macOS 可识别进程来源）
- **中间 Flow List**：请求列表表格，固定列包括序号、Method（彩色 badge：GET=绿、POST=橙、PUT=蓝、DELETE=红）、Name（请求路径）、Status（状态码，错误红色高亮）、Size、Time、Content-Type。支持列宽调整和列排序
- **右侧/下方 Flow Content**：请求和响应详情，可切换水平/垂直分栏布局。包含 Headers/Body/Cookies/Auth/Query/Raw 等 Tab
- **底部状态栏**：显示请求总数、过滤状态、SSL 状态等

### 布局优缺点分析

**优点：**
- 三栏布局信息密度高，一目了然
- Method 彩色标签视觉辨识度高
- 域名树支持 App 分组，便于定位特定应用的请求
- 布局可切换（水平/垂直），适应不同屏幕尺寸
- 右键菜单丰富，操作路径短

**缺点：**
- 没有 Waterfall 时序图 Tab（需要通过其他方式查看时序）
- 没有 Dashboard 统计面板
- FilterBar 不如 Knot 的 Chip 式过滤直观

### Knot 与 Proxyman 差异

| 对比点 | Proxyman | Knot |
|--------|----------|------|
| 内容区 Tab | 无（仅请求列表+详情） | List / Waterfall / Dashboard 三个 Tab |
| 过滤方式 | 工具栏搜索 + Multiple Filters 弹窗 | FilterBar Chip 快速筛选 + 搜索框 |
| 域名树分组 | 按域名 + 按 App | 仅按域名 |
| 详情面板布局 | 可水平/垂直切换，可独立窗口 | 仅垂直分栏（上下布局） |
| 录制控制 | 工具栏红色圆点按钮 | 工具栏播放/停止按钮 |
| 状态栏 | 简洁，显示请求数和状态 | 显示请求数 + 流量 + 内存 + 连接数 |

### Knot 中尚未实现的 Proxyman 功能

- **App 级别分组**: Proxyman 可按发起请求的 App 进程分组显示
- **布局切换**: Proxyman 支持水平/垂直布局切换，Knot 仅支持固定的上下分栏
- **独立详情窗口**: Proxyman 可将详情面板拖出为独立窗口
- **列宽调整和自定义列**: Proxyman 支持调整表格列宽和自定义显示的列
- **右键 SSL Proxying 快捷操作**: 在域名树右键可直接启用/禁用 SSL 解密
