Plugin Folder Convention

Each plugin folder follows a consistent pattern:

Plugins/HTTP1/
├── HTTP1Plugin.swift  ← required
│   implements ProtocolPlugin
│   canMatch() + buildPipeline()
├── HTTPCaptureHandler.swift  ← NIO handler(s)
│   the actual ChannelHandler
└── HTTPRecorder.swift  ← recording
    implements ProtocolRecorder
    buildFlowRecord()

Rules:

  • *Plugin.swift — always present, entry point
  • *Handler.swift — NIO handlers (0 or more)
  • *Recorder.swift — recording (0 or 1, leaf plugins only)
  • *Decoder.swift — wire format decoding (if needed)

What goes where:

Framework/ Plugin protocol, registry, dispatcher
Plugins/X/ Protocol-specific: match, handle, record
Proxy/ Shared: server bootstrap, cross-cutting handlers
Storage/ DAO, Schema, Model — protocol-agnostic
