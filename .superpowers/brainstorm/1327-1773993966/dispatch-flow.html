Match & Dispatch Flow

A TCP connection arrives — how the protocol tree processes it

Example: HTTPS request via proxy (HTTP CONNECT → TLS → HTTP/1.1)
① Raw bytes arrive on TCP port 8034
ProtocolDispatcher.detect(buffer, tcpNode.children)
HTTP1Plugin.canMatch("CONN...") → .yes(90)
TLSPlugin.canMatch(0x43≠0x16) → .no
SOCKS5Plugin.canMatch(0x43≠0x05) → .no
MQTTPlugin.canMatch(...) → .no
→ Winner: HTTP1Plugin (confidence 90)

② HTTP1Plugin.buildPipeline() — adds HTTP decoder
Decodes: CONNECT example.com:443 HTTP/1.1
Detects this is a CONNECT request → sends 200 → strips HTTP handlers
→ Emits re-detect event with raw bytes from client

③ Re-detect: now try HTTP1's children on new bytes
But CONNECT tunnel data isn't HTTP1's child — it's a new TCP stream
→ Re-enter TCP subtree (same as SOCKS5 unwrap)

④ ProtocolDispatcher.detect(buffer, tcpNode.children)
HTTP1Plugin.canMatch(0x16≠HTTP) → .no
TLSPlugin.canMatch(0x16=ClientHello) → .yes(100)
→ Winner: TLSPlugin

⑤ TLSPlugin.buildPipeline() — TLS handshake (async)
Extract SNI → generate cert → NIOSSLServerHandler
ALPN negotiated: http/1.1
→ Handshake complete, re-detect with metadata {alpn: "http/1.1"}

⑥ Detect TLS children with decrypted bytes
HTTP1Plugin.canMatch("GET /...") → .yes(90)
HTTP2Plugin.canMatch(metadata.alpn≠"h2") → .no
→ Winner: HTTP1Plugin (under TLS this time)

⑦ HTTP1Plugin.buildPipeline(context: {parent: "tls"})
Adds HTTPCaptureHandler with isSSL: true
Creates HTTPRecorder with encrypted: false, decrypted: true
→ Capturing decrypted HTTPS traffic ✓

Key Concept: "Re-detect" Protocol

Three types of plugins based on how they interact with children:

Leaf Plugin No children. Matches, builds pipeline, done.
Examples: MQTT, Redis, NTP, DNS
Unwrap Plugin Unwraps a layer, then re-detects children with the unwrapped data.
May be async (TLS handshake) or sync (HTTP CONNECT sends 200 then done).
Examples: TLS, SOCKS5, HTTP CONNECT
Inspect Plugin Matches, captures/records data, may also have children for sub-protocols.
Examples: HTTP1 (child: WebSocket), HTTP2 (child: gRPC)
